1-D DP

Recipe

  1. State: dp[i] = answer for the prefix ending at / of length i.
  2. Transition: how dp[i] depends on smaller states (try every "last decision").
  3. Base case and answer location.
  4. Optimise memory when dp[i] only needs the last few states.

Start with top-down recursion + @cache if the recurrence is clearer; convert to bottom-up when needed.

Climbing stairs  dp[i] = dp[i-1] + dp[i-2]
