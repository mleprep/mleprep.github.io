153. Find Minimum in Rotated Sorted Array

MediumLeetCode ↗★ Blind 75rotated
Asked at 14Microsoft51Amazon48Google40Bloomberg39Meta38Goldman Sachs54Walmart Labs43TikTok41Infosys39Yandex36tcs36Oracle35Uber30LinkedIn20

Compare nums[mid] with nums[hi]: if mid is bigger, the drop (minimum) is to the right; otherwise mid could be the min, so hi = mid.

[4 5 6 7 0 1 2]
 lo    mid   hi   7 > 2  -> lo = mid+1
         lo m hi  1 < 2  -> hi = mid ... -> 0

Complexity: O(log n).

class Solution:
    def findMin(self, nums: List[int]) -> int:
        lo, hi = 0, len(nums) - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if nums[mid] > nums[hi]:
                lo = mid + 1
            else:
                hi = mid
        return nums[lo]

assert Solution().findMin([3, 4, 5, 1, 2]) == 1
assert Solution().findMin([4, 5, 6, 7, 0, 1, 2]) == 0
assert Solution().findMin([11, 13, 15, 17]) == 11

class Solution {
    public int findMin(int[] nums) {
        int lo = 0, hi = nums.length - 1;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (nums[mid] > nums[hi]) lo = mid + 1; else hi = mid;
        }
        return nums[lo];
    }
}

func findMin(nums []int) int {
	lo, hi := 0, len(nums)-1
	for lo < hi {
		mid := lo + (hi-lo)/2
		if nums[mid] > nums[hi] { // the drop is to the right of mid
			lo = mid + 1
		} else {
			hi = mid
		}
	}
	return nums[lo]
}
