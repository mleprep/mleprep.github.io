# 1-D DP

**Recipe**
1. **State**: `dp[i]` = answer for the prefix ending at / of length `i`.
2. **Transition**: how `dp[i]` depends on smaller states (try every "last decision").
3. **Base case** and **answer location**.
4. Optimise memory when `dp[i]` only needs the last few states.

Start with top-down recursion + `@cache` if the recurrence is clearer; convert to bottom-up when needed.

```viz
Climbing stairs  dp[i] = dp[i-1] + dp[i-2]
i     0  1  2  3  4  5
dp    1  1  2  3  5  8
```

| Pattern | Examples |
|---|---|
| Fibonacci-like (`i-1`, `i-2`) | 70, 746, 198, 213, 91 |
| Unbounded knapsack (`dp[a] = min/sum over items`) | 322, 279, 377, 518 |
| 0/1 knapsack (iterate capacity **downward**) | 416, 494 |
| "Best ending at i" + global max | 152, 300, 53 |
| Expand around centre / interval | 5, 647 |

## 213. House Robber II | Medium

Circle → the first and last houses can't both be robbed. Answer = `max(rob(nums[1:]), rob(nums[:-1]))` (single house: itself).

## 5. Longest Palindromic Substring | Medium
related: 647, 516, 125
tags: blind75, expand-around-center

Every palindrome has a centre (a char or a gap between chars: `2n−1` centres). Expand outward from each while ends match; keep the longest.

```viz
b a b a d
  ^          centre 'a' -> "bab"(1..3)  -> expand fails at d
```

**Complexity:** O(n²) time, O(1) space (Manacher's is O(n)).

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        best = (0, 0)
        for c in range(2 * len(s) - 1):
            l, r = c // 2, (c + 1) // 2
            while l >= 0 and r < len(s) and s[l] == s[r]:
                l, r = l - 1, r + 1
            if r - l - 1 > best[1] - best[0]:
                best = (l + 1, r)
        return s[best[0]:best[1]]
# test

assert Solution().longestPalindrome("cbbd") == "bb"
assert Solution().longestPalindrome("a") == "a"
```

```java
class Solution {

            while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
            if (r - l - 1 > br - bl) { bl = l + 1; br = r; }
```


```python
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        INF = amount + 1
        dp = [0] + [INF] * amount
        for a in range(1, amount + 1):
```

## 416. Partition Equal Subset Sum | Medium
related: 494, 698
tags: 0-1-knapsack

Need a subset summing to `total / 2`. 0/1 knapsack over reachable sums: iterate the sum **downward** so each number is used once. (Python bitset trick: `bits |= bits << x`.)

**Complexity:** O(n · total/2).

```python
class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total = sum(nums)
        if total % 2:
            return False
        target = total // 2
        dp = [True] + [False] * target
        for x in nums:
            for s in range(target, x - 1, -1):
                dp[s] = dp[s] or dp[s - x]
        return dp[target]
```

```python
        st, best = [-1], 0
        for i, ch in enumerate(s):
            if ch == "(":
                st.append(i)
            else:
                st.pop()
                if not st:
                    st.append(i)
                else:
```

## 673. Number of Longest Increasing Subsequence | Medium
related: 300
tags: lis, counting

Alongside `len[i]` (LIS ending at i) keep `cnt[i]` (how many). For `j < i` with `nums[j] < nums[i]`: a longer length resets the count; an equal length adds `cnt[j]`.

```python
    def findNumberOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        length, cnt = [1] * n, [1] * n
        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:
                    if length[j] + 1 > length[i]:
                        length[i], cnt[i] = length[j] + 1, cnt[j]
                    elif length[j] + 1 == length[i]:
```

```java
        int[] len = new int[n], cnt = new int[n];
        for (int i = 0; i < n; i++) {
            len[i] = cnt[i] = 1;
            for (int j = 0; j < i; j++) {
                if (nums[j] >= nums[i]) continue;
                if (len[j] + 1 > len[i]) { len[i] = len[j] + 1; cnt[i] = cnt[j]; }
                else if (len[j] + 1 == len[i]) cnt[i] += cnt[j];
            }
            if (len[i] > best) { best = len[i]; res = cnt[i]; }
            else if (len[i] == best) res += cnt[i];
```

## 132. Palindrome Partitioning II | Hard
related: 131, 5
tags: dp, expand-around-center

`cuts[i]` = min cuts for `s[:i]`. Expand around every centre; each palindrome `s[l..r]` gives `cuts[r+1] = min(cuts[r+1], cuts[l] + 1)`. Base `cuts[0] = −1`.

**Complexity:** O(n²) time, O(n) space.

```python

    def minCut(self, s: str) -> int:
        n = len(s)
        cuts = [i - 1 for i in range(n + 1)]       # worst case: cut between every char
        for c in range(n):
            for l, r in ((c, c), (c, c + 1)):
                while l >= 0 and r < n and s[l] == s[r]:
                    cuts[r + 1] = min(cuts[r + 1], cuts[l] + 1)
                    l, r = l - 1, r + 1
        return cuts[n]
```

## 1235. Maximum Profit in Job Scheduling | Hard

Sort jobs by end time. `dp[i]` = best profit using the first i jobs = `max(dp[i−1], profit[i] + dp[j])` where `j` = number of jobs ending ≤ start[i] (binary search).

```viz

```

**Complexity:** O(n log n).

```python

    def jobScheduling(self, startTime: List[int], endTime: List[int], profit: List[int]) -> int:
        jobs = sorted(zip(endTime, startTime, profit))
        ends = [e for e, _, _ in jobs]
        dp = [0] * (len(jobs) + 1)
        for i, (e, s, p) in enumerate(jobs, 1):
            j = bisect.bisect_right(ends, s, 0, i - 1)     # jobs finishing by time s
            dp[i] = max(dp[i - 1], dp[j] + p)
        return dp[-1]
```

```java
        int n = startTime.length;
        Integer[] idx = new Integer[n];
        for (int i = 0; i < n; i++) idx[i] = i;
        Arrays.sort(idx, (a, b) -> endTime[a] - endTime[b]);
        int[] dp = new int[n + 1];

        }
        return dp[n];
    }
```

## 790. Domino and Tromino Tiling | Medium
related: 70, 1137, 91
tags: dp, recurrence

Let `f(n)` = tilings of a full `2 × n` board and `p(n)` = tilings of a `2 × n` board plus **one protruding cell**. ```viz


**Complexity:** O(n) time, O(1) space.

## 1406. Stone Game III | Hard
related: 877, 1140
tags: minimax, dp

Zero-sum game → track the **score difference** for the player to move: `dp[i] = max over k ∈ {1,2,3} of (sum of stones i..i+k−1) − dp[i+k]`. Alice wins if `dp[0] > 0`, Bob if `< 0`, otherwise tie.

**Complexity:** O(n) time, O(1) extra space possible (only dp[i+1..i+3] needed).

```python

        for i in range(n - 1, -1, -1):
            take, best = 0, float("-inf")
            for k in range(3):
                if i + k < n:
                    take += stoneValue[i + k]
                    best = max(best, take - dp[i + k + 1])
            dp[i] = best
        return "Alice" if dp[0] > 0 else "Bob" if dp[0] < 0 else "Tie"
```
