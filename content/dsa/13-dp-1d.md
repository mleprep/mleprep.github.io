# 1-D DP

**Recipe**
1. **State**: `dp[i]` = answer for the prefix ending at / of length `i`.
2. **Transition**: how `dp[i]` depends on smaller states (try every "last decision").
3. **Base case** and **answer location**.
4. Optimise memory when `dp[i]` only needs the last few states.

Start with top-down recursion + `@cache` if the recurrence is clearer; convert to bottom-up when needed.

```viz
Climbing stairs  dp[i] = dp[i-1] + dp[i-2]
i     0  1  2  3  4  5
dp    1  1  2  3  5  8
```

| Pattern | Examples |
|---|---|
| Fibonacci-like (`i-1`, `i-2`) | 70, 746, 198, 213, 91 |
| Unbounded knapsack (`dp[a] = min/sum over items`) | 322, 279, 377, 518 |
| 0/1 knapsack (iterate capacity **downward**) | 416, 494 |
| "Best ending at i" + global max | 152, 300, 53 |
| Expand around centre / interval | 5, 647 |

## 5. Longest Palindromic Substring | Medium
related: 647, 516, 125
tags: blind75, expand-around-center

```problem
Return the longest substring of `s` that is a palindrome (any one of them if there are ties).

**Example:** `"babad"` → `"bab"` (or `"aba"`); `"cbbd"` → `"bb"`

**Constraints:** length ≤ 1000.
```

Every palindrome has a centre (a char or a gap between chars: `2n−1` centres). Expand outward from each while ends match; keep the longest.

```viz
b a b a d
  ^          centre 'a' -> "bab"(1..3)  -> expand fails at d
```

**Complexity:** O(n²) time, O(1) space (Manacher's is O(n)).

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        best = (0, 0)
        for c in range(2 * len(s) - 1):
            l, r = c // 2, (c + 1) // 2
            while l >= 0 and r < len(s) and s[l] == s[r]:
                l, r = l - 1, r + 1
            if r - l - 1 > best[1] - best[0]:
                best = (l + 1, r)
        return s[best[0]:best[1]]
# test

assert Solution().longestPalindrome("cbbd") == "bb"
assert Solution().longestPalindrome("a") == "a"
```

## 32. Longest Valid Parentheses | Hard


Stack of indices, seeded with `-1` as the "last invalid position". `(` → push index. `)` → pop; if the stack is empty, push this index as the new base; else the valid run length is `i − stack[-1]`.

```viz
s = ) ( ) ( ) )
i   0 1 2 3 4 5
i=0 ')' pop -1 -> empty -> push 0
i=2 ')' pop 1  -> len 2-0 = 2
i=4 ')' pop 3  -> len 4-0 = 4   <- best
```

**Complexity:** O(n).

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        st, best = [-1], 0
        for i, ch in enumerate(s):
            if ch == "(":
                st.append(i)
            else:
                st.pop()
                if not st:
                    st.append(i)
                else:
                    best = max(best, i - st[-1])
        return best
```

```problem
Return how many longest strictly increasing subsequences `nums` has.

**Example:** `[1,3,5,4,7]` → `2` (1, 3, 4, 7 and 1, 3, 5, 7); `[2,2,2,2,2]` → `5`
```

Alongside `len[i]` (LIS ending at i) keep `cnt[i]` (how many). For `j < i` with `nums[j] < nums[i]`: a longer length resets the count; an equal length adds `cnt[j]`.

```python
    def findNumberOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        length, cnt = [1] * n, [1] * n
        for i in range(n):
            for j in range(i):

                    elif length[j] + 1 == length[i]:
                        cnt[i] += cnt[j]
        best = max(length)
        return sum(c for l, c in zip(length, cnt) if l == best)
```

```problem
Return the minimum number of cuts needed to split `s` into pieces that are all palindromes.

**Example:** `"aab"` → `1` (`"aa" | "b"`); `"a"` → `0`

**Constraints:** length ≤ 2000.
```

`cuts[i]` = min cuts for `s[:i]`. Expand around every centre; each palindrome `s[l..r]` gives `cuts[r+1] = min(cuts[r+1], cuts[l] + 1)`. Base `cuts[0] = −1`.

**Complexity:** O(n²) time, O(n) space.

```python

    def minCut(self, s: str) -> int:
        n = len(s)
        cuts = [i - 1 for i in range(n + 1)]       # worst case: cut between every char
        for c in range(n):
            for l, r in ((c, c), (c, c + 1)):
                while l >= 0 and r < n and s[l] == s[r]:
                    cuts[r + 1] = min(cuts[r + 1], cuts[l] + 1)
                    l, r = l - 1, r + 1
        return cuts[n]
```

Word Break, minimized: `dp[i]` = fewest extra characters in `s[i:]`. Either skip `s[i]` (cost 1 + `dp[i+1]`) or, for every dictionary word starting at `i`, jump past it for free. A trie over the dictionary avoids rebuilding substrings.

```python
class Solution:
    def stoneGameIII(self, stoneValue: List[int]) -> str:
        n = len(stoneValue)
        dp = [0] * (n + 3)
        for i in range(n - 1, -1, -1):
            take, best = 0, float("-inf")
            for k in range(3):
                if i + k < n:
                    take += stoneValue[i + k]
                    best = max(best, take - dp[i + k + 1])
            dp[i] = best
        return "Alice" if dp[0] > 0 else "Bob" if dp[0] < 0 else "Tie"
```

```java
class Solution {
    public String stoneGameIII(int[] stoneValue) {
        int n = stoneValue.length;
        int[] dp = new int[n + 3];
        for (int i = n - 1; i >= 0; i--) {
            int take = 0, best = Integer.MIN_VALUE;
            for (int k = 0; k < 3 && i + k < n; k++) {
                take += stoneValue[i + k];
                best = Math.max(best, take - dp[i + k + 1]);
            }
            dp[i] = best;
        }
        return dp[0] > 0 ? "Alice" : dp[0] < 0 ? "Bob" : "Tie";
    }
}
```

```go
func stoneGameIII(stoneValue []int) string {
	n := len(stoneValue)
	dp := make([]int, n+1) // dp[i] = best (mine - theirs) when it is my turn at i
	for i := n - 1; i >= 0; i-- {
		take, best := 0, math.MinInt
		for k := 0; k < 3 && i+k < n; k++ {
			take += stoneValue[i+k]
			best = max(best, take-dp[i+k+1])
		}
		dp[i] = best
	}
	switch {
	case dp[0] > 0:
		return "Alice"
	case dp[0] < 0:
		return "Bob"
	}
	return "Tie"
}
```
